# 17 · 图表生成、统一排版与视觉验收

> 适用语言：通用。配套：`cards/dimensions/figure-visual-repair.md`（修图卡片）、09-mechanics §十（页级目检）、10-chinese §七（图内文字语言）、`page_fill`（半空页，职责不扩大）。
>
> 依据三件事：范文 Bu 2024 的图表组织（12 图 1 表，单栏为主，图例内置，示意图为纯矢量线稿；只参照功能与版式，不复制图形与文字）；第一篇已过审的绘图实现（一个样式层 + 语义字典 + 图件清单）；第二篇这次修图暴露的五类问题——尺寸不一、图例重叠、箭头混乱、色条遮挡、浮动体空白页。

## 一、尺寸由模板决定，不由绘图脚本决定

- 从目标模板取两个物理宽度：单栏 `\columnwidth`、跨栏 `\textwidth`（编译一次 `\the\columnwidth` 或查模板说明，换算成英寸）。绘图脚本的 `figsize` 宽度**等于**其中之一，LaTeX 侧用 `width=\columnwidth` 或 `width=\textwidth` 原尺寸嵌入，不靠 `includegraphics` 缩放——缩放会让字号与线宽偏离样式层的设定。
- 高度按图类定，同类图共用一个常量（证据链各图一个、SNR 曲线族一个、面板图按行列数一个）。**不要求全稿所有图同高**。`height=…\textheight,keepaspectratio` 只作防溢出的上限。
- 单栏优先。跨栏只给面板 ≥ 4、宽表、或横向流程图；跨栏图落在 `figure*`，其出现页会晚于引用页，版面检查时要看它。

## 二、一个样式层，所有图从它导入

样式层是一个模块（第一篇的实例：`rcParams` 块 + `COLORS` / `MARKERS` 字典 + `FIGURES` 清单），每个绘图脚本只导入、不自定义。改样式只改这一处，然后**全套图重生成**——这就是第二篇「每次画的都不一样」的根治办法。样式层里定的四件事：

| 项 | 规则 |
|---|---|
| 字体层级 | 标题 ≥ 轴标签 ≥ 刻度 ≥ 图例；落版后任何文字不小于正文脚注字号。具体磅值由模板正文字号推出，写在样式层，不写在本文件 |
| 线宽与视觉重量 | 所提方法主线最重，基线次之，真值细虚线，量测 / 杂波点最轻；同类图之间视觉重量一致 |
| 外框与绘图区 | 同类图相同的 spine、网格、留白；面板图用共享轴与共享图例 |
| 导出参数 | 见 §五；同样只写一次 |

## 三、固定语义映射：谁是谁，全稿一个颜色

方法、内部变体、外部基线、真值、量测、杂波各占一组**颜色 + 线型 + marker** 三通道，写成字典，键是对象 id 而不是图号。规则：

- 同一对象全稿同色同 marker，不因图而变；新增对象加字典项，不复用已占用的颜色。
- 调色板色盲安全（Okabe–Ito 一类），黑色留给「全部」或参考线；真值固定为细虚线，杂波固定为最浅灰点。
- 具体色值属于项目样式层，不是本方法的硬规则。

## 四、按图类的规范

**图例**：不遮数据；面板图一套共享图例放图外顶部或底部；条目顺序 = 正文首次提及顺序；条目文字用术语表冻结词。位置按数据分布定，**不固定在同一角**。

**面板**：编号 (a)(b)… 与图注一一对应；同一量纲共享坐标范围与刻度；面板间距一致；每个面板只回答一个问题。

**流程图 / 示意图**：纯矢量线稿，方框、箭头、字体只用一种风格；箭头只表达数据流向，一条边一个箭头，交叉必须绕开或标记；模块名与正文小节标题一致。范文的示意图只有点、椭圆、星形与一条基线，复杂度以此为上限。

**轨迹图**：z-order 固定为 杂波 < 量测 < 真值 < 估计；起点、终点有 marker；同种子证据链的各图共用同一坐标范围（02-narrative 结果章）；失败案例图与成功案例同尺寸同范围。

**统计图**：x 轴等步（SNR、目标数）；y 轴带单位；区间或误差条在图注写明口径（自助区间 / 标准差 / 逐点）；对数轴在轴标签注明；不用截断 y 轴制造视觉差异。

**热图 / 色图**：色条放绘图区外，不遮任何单元；色条标签带单位；离散量用离散色阶并给刻度；配色单调（viridis 一类），红绿对比不用。

## 五、导出与字体

- 线图、流程图、轨迹图一律矢量 PDF；`pdf.fonttype = 42`、`ps.fonttype = 42` 嵌入 TrueType；`pdffonts <fig>.pdf` 确认无 `Type 3` 且全部 `emb = yes`。
- 栅格图（热图、密度图、照片）有效 DPI = 像素数 ÷ 落版英寸 ≥ 300，照片类 ≥ 200；`pdfimages -list main.pdf` 查嵌入后的实际 DPI。
- `bbox_inches="tight"` 之后实际画幅会变，导出后用 `pdfinfo` 核一次页面尺寸是否仍等于目标宽度。
- 同一图同时导出 PDF（入稿）与 PNG（预览、批注），文件名相同只换扩展名。

## 六、表格

- 三线表（`booktabs`），无竖线；单位写在表头，不写进单元格。
- 同一列同一精度；数字右对齐或用 `siunitx` 的 `S` 列按小数点对齐；精度不高于数据本身的精度（06-evidence 二次舍入）。
- 数字只来自生成宏；表注写统计口径与样本量。
- 单栏优先；列数超过单栏可读上限或含长公式时才用 `table*`。

## 七、双重目检：独立图件一次，嵌入 PDF 一次

独立图件 PDF 逐张看，嵌入后 PDF 页级再看一次（09-mechanics §十）。两次都过八项：

1. 边缘无裁切（标签、图例、色条完整）
2. 图例不压数据、不压面板编号
3. 箭头方向与正文机制一致，无交叉歧义
4. 色条与轴标签不重叠
5. 落版后最小字号仍可读（与正文脚注比）
6. 同类相邻图的视觉重量一致（线宽、留白、字号）
7. 图注编号、面板编号、正文引用三者一致
8. 图内文字用术语表冻结词，语言按 10-chinese §七

## 八、图尺寸变化后必须重做的事

任何 `figsize`、跨栏 / 单栏、面板数的改动都会移动浮动体：重跑 `page_fill`；核对浮动顺序 = 首次引用顺序；证据链各图仍按链的顺序出现；位置参数用 `[t]` / `[tb]`，不用 `[H]`；`\FloatBarrier` 只在章末；若只改了图不改文字，`page_delta` 残差应为 0。

## 九、明确不作为硬规则的

当前论文的具体英寸、字号、色值、页数与图数量；「所有图同高」；「图例固定在同一位置」；「中文稿图内文字必须中文化」（语言按图类分层，见 10-chinese §七）。这些由期刊模板、图形类型和最终物理尺寸决定，写在项目样式层，不写在本方法里。

## 十、本轮不做的

自动美学评分、图像检测、图件 manifest、新的门禁脚本。`page_fill` 只管半空页，不扩大为图形质量检测器。图表缺陷的处理走 [figure-visual-repair 卡片](../cards/dimensions/figure-visual-repair.md)，触发来自目检，不来自脚本。
