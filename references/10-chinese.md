# 10 · 中文母稿特有条目

> **适用语言：中文（部分条目对中→英翻译轮同样适用，已单独标注）**

这一节是本项目投入时间最多的部分。中文期刊论文的失败模式与英文不同，且不能靠通用写作规则覆盖。

## 一、量词歧义（最高风险）

中文的「各 / 每」必须让读者一眼看出**分配对象**，且要与表格里的口径交叉核对。

### 事故

| 原文 | 问题 |
|---|---|
| 「它们在 $\{0,4,8,12,16\}$ dB 的**各 500 次**仿真中无一通过成功判据」 | 「各 500 次」可被读成 per-condition（总 2500）或 per-total（总 500）。而表 1 给的是每条件 100 次 —— 两处口径冲突，**样本量会被误读成 5 倍** |

### 修法

```
✓ 「在 {0,4,8,12,16} dB 五个条件下，每个变体合计 500 次仿真，无一通过成功判据」
```

显式说明**总数与分摊方式**。

### 执行

凡涉及计数、分母、样本量的句子逐句复查，并与参数表交叉一致。这是**诚信风险而非文笔问题**。

### 反向护栏：「同一」后不接数量词

```
✗ 「同一三个条件」
✓ 「同一条件下」（直接删数量词）
```

不要用「插入一个类别名把量词隔开」的写法——本项目试过并放弃了。

## 二、中英混排

### 白名单机制

中文正文可保留领域通用缩写、专名及作者已采纳的词形。以下是历史缩写示例，不是排他白名单：

```
SNR  RMSE  GOSPA  OSPA  CFAR  P_D  P_fa  TBD  ML-PDA  GM-PHD
```

其余词按概念和语境使用当前术语表。分布名、方法专名也可保留英文，例如 Poisson；不要求所有中文稿采用同一选择。

### 执行方式不是通读

1. 先建缩写白名单
2. `grep` 正文中所有连续拉丁字母串
3. 白名单之外逐项判定，区分专名、数学符号、伪代码和多余中英混排后再替换

### 典型残留

英文单词夹在中文句里是从英文稿或代码变量直译留下的痕迹，也是「实验报告腔」最易被识别的外部特征：

```
✗ detection rate   runtime   arc   payload   case   trial   frame
✓ 检测率  运行时间  航迹段  （删）  场景  仿真次  帧
```

### 缩写首现格式

```
中文译名（英文全称, 缩写）
```

例：「概率数据关联（probabilistic data association, PDA）」

冻结成表，同一概念全稿只用一个词。

## 三、行话要洗两遍

**默认第一遍产物不合格。**

```
第一遍：英文行话 / 代码术语 → 中文
第二遍：译出来的「中文行话」→ 目标期刊的中文
```

第二遍的验收判据是一个可回答的问题：

> **这个说法能在目标期刊已发表论文里找到吗？**

只存在于你的代码、仓库、实验脚本或内部文档里的词一律替换：

| 第一遍产物（仍是黑话） | 第二遍（期刊中文） |
|---|---|
| 6300 次核心运行 | 每个条件 100 次 Monte Carlo 仿真 |
| 七个预设算法 | 七种对比算法 |
| 评价协议 | 性能评价方法 |
| 成功回放 | 成功的仿真实例 |
| 核心网格 | 主实验条件集合 |

**这一步最容易被跳过**——译成中文之后读起来「已经是中文了」，于是判定完成。

## 四、多层定语复合名词

中文比英文更容易堆定语，因为不需要介词。

**检测判据**（两条同时满足即为自造词）：

- 三层以上修饰语连缀
- 在任何被引文献中都查不到

一律拆成主谓句或动词短语：

| 自造复合名词 | 拆解 |
|---|---|
| 可认证分支定界前沿搜索 | 带上界剪枝的分支定界搜索，给出精确值或误差有界的区间估计 |
| 确定性刚体匀速真值协议 | 目标作匀速直线运动，编队保持刚性 |
| 配对区间覆盖零 | 两者之差的 95% 置信区间包含零，差异在统计上不可分辨 |
| 编队条件标记关联边缘 | （保留——这是本文定义的核心概念，且在方法章有完整定义） |

最后一行是边界：**本文正式定义并反复使用的核心术语不在此列**，判据仍是「有没有定义、是不是承载概念」。

## 五、名词链与翻译腔

看到「源于 / 表征 / 体现 / 来自」后面接一长串名词修饰时改写。

| 翻译腔 | 改写 |
|---|---|
| 「该退化源于低信噪比条件下幅度证据不足导致的关联歧义增加」 | 「在低信噪比下幅度证据不足，关联歧义随之增加，因而出现该退化。这并不表示⋯」 |

做法：

1. 用**显式因果连接词**拆开名词链（「A 是因为 B」）
2. 范围限制**另起一句**

压缩名词链有双重代价——读起来是翻译腔，且**掩盖因果方向和结论边界**，读者无法判断作者到底承认了什么。

## 六、伪代码与浮动体的语言

| 元素 | 语言 | 理由 |
|---|---|---|
| 算法伪代码体（Require/Ensure、控制流关键词、步骤语句、注释） | **英文** | 中文写伪代码不合期刊惯例 |
| 浮动体名（「算法 1」「图 3」「表 2」） | **中文** | 与全文图表 caption 语言一致的中文期刊惯例 |
| 图注 / 表题 | **中文** | 同上 |

**一次定死，避免逐轮反复。**

改语言时数学符号与公式交叉引用逐一保持，行序与语义一一对应。

若目标期刊模板另有明文规定，以模板为准。

## 七、图内文字：按图类分层，不是一律中文化

图内文字的语言规则只在本节维护；图的尺寸、样式层、语义映射、导出与目检在 [17-figures-tables-and-visual-qa.md](17-figures-tables-and-visual-qa.md)，那里不设「中文化」硬规则。

**语言由当前稿件与作者决定。** 下表是来源论文 r22 的历史做法，不能用它拒绝作者后来要求的中文统计图或独立英文图件：

| 图类 | 来源论文定稿的**实际**做法 | 判据 |
|---|---|---|
| **证据链图**（场景、真值轨迹、含噪观测、代表帧量测、最终输出） | 图例与状态注释**中文化**：「成功」「失败」「成员」「领航」 | 这类图的文字是**读者要逐个对照正文读**的语义标签 |
| **统计图**（SNR 曲线、消融、敏感性、runtime） | 轴标签、图例、子图标题**保持英文通用式**：`SNR (dB)`、`Mean GOSPA (m)`、`Success rate`、`leader`/`follower`、`(a) Prespecified success gate` | 这类是量纲与指标名，英文是领域通用写法，中译反而生硬 |

核实方式：`pdftotext` 抽取定稿 PDF + grep 图生成器的 `set_xlabel`/`set_ylabel`/`legend`。

### 与图类无关的三条硬规则

| 元素 | 处理 |
|---|---|
| **跨整图大标题**（`suptitle` / 图顶部的 `fig.text`） | **一律删除**——LaTeX 图注承担标题，期刊图不带内嵌 title。来源论文定稿 `suptitle`/`fig.text` grep **零命中** |
| 子图标题 `(a)(b)(c)` | 可以有，但**必须与 LaTeX 图注里的编号大小写一致**。图内写 `A`、图注写 `(a)` 是页级才能发现的不符 |
| 从 LaTeX 复制来的连字符 | `slot--measurement` 会原样渲染成两个短横。改成 `slot-to-measurement` |

### 流程要求

**改图前先在一张样张上把规范一次定死并过审，再批量重跑，且批量后仍要抽查。** 图的返工成本按张数放大——一组六张图，规范错一次就是六张白画。

### 若最终要出英文版

两种语言尽量共用数据和绘图逻辑，通过语言参数与文字映射分别输出；已验收的旧语言图件保持原身份，新语言写到新目录。翻译标签后仍需检查文字长度、字体回退、上下标字号和图例遮挡，不能因数据没变就省掉目检。修改共享生成器时，定向核查未授权改变的语言输出及数值宏未漂移。


## 八、【中→英翻译轮】

母稿经确认后才启动。

1. **中英术语表冻结**（formation / group / slot / target / measurement / clutter / false alarm ⋯）
2. **逐段从中文翻译，不沿用旧英文稿的句面结构**
3. 范文只作术语和段落功能参照，**不复制句子**
4. 翻译时一并落实的 copy edits：
   - percentage points（不写 %，当指差值时）
   - 缩写全称展开位置
   - `refs.bib` 大小写保护（`{ML-PDA}`）
   - 数字风格统一
   - 交叉引用完整性
5. 重编译后**中英逐段反向核对**、缩写首次定义检查、图注独立可读性检查
6. **翻译不变量机器核对**：把中英段落写成 `pairs.json`（`[{"id": "05#12", "old": "中文段", "new": "English paragraph"}]`），跑
   `python scripts/semantic_diff.py --pairs pairs.json --mode ze`。数字、单位、引用键、图表号逐段必须一致（HARD_FAIL）；
   方向词（高于/低于、包含零/不包含零、至少/至多、已知/未知、支持/未显示、平均/逐场景）跨语言只作待审；
   缩写差异在 `ze` 模式只提示，因为英文稿会在首现处展开缩写。人工反向核对（第 5 步）仍然要做——脚本只查事实，不查语气与逻辑。

### 初译交付前的双向语义核对

- 英文每个实质成分都能指回中文，中文的限定都有对应表达。逐项检查三维、全部、各、仍、也、至多等易漏成分，不能只看数字和引用是否相同。
- 并列不能擅自译成因果、让步或类比；`and`、`although`、`therefore` 并不等价。等价关系不能弱化成 `yields`，适用性不能凭空添加 `which makes … suitable` 的因果解释。连接词按原文真实关系选，不做固定词对词替换。
- 初译即写成自然的学术英文。操作关系优先用动词，例如分别传播均值与协方差；条件直接写 `if D=1`，不机械搬入代码分支的说法。句首 `Following …` 等分词短语的逻辑主语须与主句一致。
- 专业名词短语按所指机制和文献语境核实。文献中出现 `actual measurement` 不代表它能表达实际量测与杂波的区分；`real measurement`、`clutter reference` 等历史候选也不能未经语境判断直接复用。查不到时采用准确的普通描述或列为待审，不能把一次未检到写成领域不存在。
- 统一专业术语、符号与指标；普通等义表达允许变化，例如 `Simulations show` 与 `The simulation results show` 不必强行统一。通用去 AI 味规则仅采纳适用于技术文本的部分，不删术语内连接号、公式范围号，不加入个人化口吻。
- 翻译中发现母稿或文献概括有误时，先区分翻译错误与源文问题。翻译错误在本轮修正；源文的科学含义变更按当前授权处理，并记录中文待同步项，不能借翻译静默改母稿或加强原主张。

分章交付的块号从实际 pairs 查询，章节范围同时核对源码 label 与 PDF 印刷节号；不能从 `sec:zh-4-4` 推定它印成第 4.4 节。采用当前已确定的对照与验收方式，不把生成 pairs 或零硬失败单独当作译文通过。来源与复核入口见 [18](18-author-review-and-revision.md)。

全稿或浮动布局改变后，按 PDF 实际阅读顺序复核缩写首现；表格可能移到正文定义之前，可在表内写全称使其自足。展开缩写时也检查全称内部是否嵌套另一未定义缩写，不能只确认括号里出现过缩写。

语义比较的证明范围取决于预处理：明确哪些布局内容被归一化或排除，并保留原始源码核查。若配对工具移除了 `includegraphics` 全部可选参数，零差异不覆盖被移除的选项；宽度与浮动环境可以是已声明的版式差异，裁切、旋转等仍须核对是否影响内容。文档说明不代表现有比较脚本已自动检查这些情况。

### 英文侧的对应雷区

| 中文母稿问题 | 英文对应 |
|---|---|
| 行话 | jargon 直译（"registered cells"、"campaign"） |
| 名词链 | nominalization 堆叠 |
| 让步式连接 | "nevertheless required" → "retained because" |
| 防御句密度 | 同一预算规则适用 |

## 九、中文写作的段落节奏

中文期刊论文的段落比英文短。参考本项目定稿：

- 引言 6 段，每段 3–5 句
- 方法小节每节 2–4 段
- 结果每图配一段 2–3 句解读

上述段数与句数只作历史参考。按完整论证单元分段，长段先检查是否混入多个问题，不按句数硬拆因果关系。

## 十、中文特有的 AI 腔标志

除通用的连接词密度问题外，中文另有几个：

| 标志 | 说明 |
|---|---|
| 「值得注意的是」「需要指出的是」「不难看出」 | 高频出现即为标志，按密度清洗 |
| 四字格堆砌（「显著提升」「大幅改善」「充分验证」） | 换成具体数值 |
| 「⋯的⋯的⋯的」三重「的」 | 拆句 |
| 排比式否定清单（「不是 A、不是 B、也不主张 C」） | 见 [04-hedging.md](04-hedging.md) |
| 每段都以「首先/其次/最后」开头 | 只在真正需要枚举时用 |

清洗方法同样是**词密度扫描**而非套话清单：挑出全文异常频繁的功能词，逐处判断是否承担实际语义。

## 十一、标点承载的句法与逻辑

- 摘要段数和特别标点要求按当前稿已采纳意见执行，见 [项目适配](00-project-adaptation.md)。一般正文不一律禁分号，只在紧密并列且不宜自然拆句时保留；冒号用于引出定义或列举，不代替因果解释、过渡或推导。
- 逐处读完整句子再改标点。拆句后保留因果、转折或并列关系，补齐必要主语与指代，限定条件仍约束原结论。堆叠连接词不能修复缺失的逻辑关系。
- 扫描区分正文、关键词分隔符、公式、LaTeX 命令、代码、书目和 URL。不得整文件机械清零分号或冒号；关键词中的分号不计作正文违规。
- 英文把显示公式与前后文字作为同一句法单元检查。公式结束完整句且后接独立句时使用句号；后接同句的符号解释时按语法用逗号及小写 `where`。公式本身的运算符、小数点和数学内容保持不变，句末标点单独核对，不能凭公式末尾已有逗号就强行续句。
