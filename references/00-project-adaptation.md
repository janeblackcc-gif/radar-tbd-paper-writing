# 00 · 项目适配原则

先读使用项目已有的适配文件、规则和当前意见。这份公开方法文档不保存任何项目的任务状态、私有路径或实验协议。

## 权威与范围

- 最新且适用于当前范围的已采纳导师与作者意见优先于本 Skill 的历史规则。区分原始意见、作者采纳决定、外部建议和代理推断；后续纠正保留替代关系。
- 目标期刊、摘要段数、标点偏好、术语、图数、表格对齐及章节顺序由当前任务确定。旧例只说明原场景，不是当前稿的配置。
- 沿用项目现有大纲、证据记录和复核流程。局部修订不自动开放结构重建，不自动触发实验、构建、发布或新建 tracker。
- 保留项目自己的适配文件；升级通用规则时人工合并冲突，不用公开入口覆盖本地授权边界。

## 写作门禁

本次更新只改变方法文档，不改变脚本 CLI、配置字段、退出码、诊断状态、默认阈值或测试夹具。新增的逻辑、标点和翻译检查属于人工审核，不能声称已有脚本能自动验证。

首次接入既有稿件先 report-only 校准。工具诊断与科学有效性、作者验收分开报告；规则冲突按有效配置权限处理，不能为过旧门禁改回已否定的写法，也不能伪报通过。

`claim_ledger` 按名称及既有 `baseline_aliases` 匹配，不理解集合语义。已采纳的集合称呼可以用于摘要，但人工须确认具体成员和比较条件；获准配置后才记录对应别名，不把笼统的基线一词设为所有方法的通用别名。没有配置授权时保留诊断并解释差异。

## 按修改类型解释差异

- 纯语言轮保护数值、单位、比较方向、引用和数学含义；必要边界信息保持，承载它的旧句子不必逐字保留。
- 获准结构修改、引用纠错或公式去重可能改变数字出现次数、引用集合和段落。先明确不变量，再逐项解释预期差异；脚本的计数不等于科学含义判定。
- `macro_diff` 保护已冻结结果；获准新增结果仍须有相应来源与生成器，不能手改数字凑一致。
- `page_delta` 的零残差只在适用的受限布局轮使用，合法结构重排不以回到历史页数为目标。最终检查实际 PDF、图注、引用与内容完整性。
- 防御句位置及额度只作经校准的诊断。研究问题、模型假设、先验信息和适用条件不能因零额度删除。

## 公开与项目副本

公开仓库保留通用经验和合成回归语料。私有意见原件、会话记录、未公开稿件、内部 seed、项目路径和当前验收记录留在对应项目。公开副本与项目适配版不要求字节一致，也不会自动更新其他项目中的复制安装。
