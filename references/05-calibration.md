# 05 · 范文对标

> 适用语言：通用

没有范文，「什么算好」就没有可测量的定义。**动笔前先选定范文，不是写完了再对照。**

## 一、默认范文

```
Bu, Rao, Song. "A group target track-before-detect approach using two-stage
strategy with maximum-likelihood probabilistic data association."
IET Radar, Sonar & Navigation, 18(8):1351–1363, 2024.
DOI: 10.1049/rsn2.12574
```

选它的理由：同刊、同题材（群目标 TBD + ML-PDA）、近三年、含完整实验章，且**导师点名认可其写法**。

> 该 PDF 是第三方版权材料，不入库、不复制其句子。只作结构参照。

换方向时按同样标准另选：**同刊、近三年、同方法族、含实验章**。

## 二、对标分两层，边界写进任务约束

### 可参考层（6 条）

1. 章节递进顺序
2. 分层讲解方式（先给总体再给细节的层级）
3. 总流程图 + 算法框的展示层级
4. **先原始证据后统计曲线**的顺序
5. 术语使用语境
6. 结果段的段落功能：**目的 — 条件 — 指标 — 观察 — 原因**

### 不可继承层（5 条）

1. 句子
2. 两阶段叙述的具体措辞
3. 实验参数与判定阈值
4. **样本量**
5. 把范文结论当自己论文结果的证明

**照骨架，不照皮肤。**

### 样本量的处理是这条边界的试金石

范文用 500 次 Monte Carlo，本项目取每条件 100 次——理由是自己的区间精度论证（30 次时 95% Wilson 半宽约 0.17，100 次可接受），**不是「范文用了多少我用多少」**。

先根据核心结论和区间精度设计样本量，再看范文取值是否巧合一致。

### 不得用范文给自己的参数背书

| 改前 | 改后 |
|---|---|
| 「主实验门限工作点 $P_{fa}=0.1$ 与 Bu 等的双群配置一致 \cite{Bu_2024}，并落于 Blanding 等已发表的范围 0.05--0.25 内 \cite{Blanding_2008}。」 | 「主实验门限工作点 $P_{fa}=0.1$ 落于 Blanding 等已发表的 $P_{fa}$ 范围 0.05--0.25 内的展示点 \cite{Blanding_2008}。」 |

参数锚定要引**第三方已发表的取值范围**，删掉「与范文一致」这半句。

### 不得把范文方法的性质安到自己方法上

仿写行文可以，安性质是**技术错误**：

| 事故实例 | 问题 |
|---|---|
| 「⋯且组间可并行，总代价与组数线性增长」 | 「组间可并行」是仿 Bu 写复杂度时新写的，但与本文 §4.5 的多组机制直接矛盾——本文多组是顺序处理 |

修复：删去半句，只留「总代价与组数线性增长」。

同类高发项：「存在闭式解」「可增量更新」「无需调参」。

## 三、三列映射表

| 范文元素 | 它承担的功能 | 本文对应内容 |
|---|---|---|
| Figure 6(a) | 展示群目标原始运动 | 图 4 真值轨迹 |
| Figure 6(b) | 噪声与观测误差后的目标点 | 图 5 含噪观测 |

**表下必须写死一句**：

> 这是功能类比，不是元素编号的指定。

照抄编号或形式即为失败。本项目最终产出功能等价但**编号全不同**的七图，小节划分也不照抄导师给的清单。

## 四、量化自比

「风格」要转成可逐项核对的量表。

> **前提**：本节要求手中有范文 PDF。取不到时跳过步骤 2 和 4，直接用 [04-hedging.md](04-hedging.md) 第二节的范文无关经验预算（20 页正文内 ≤10 句限定语）作为唯一硬指标。

### 步骤

1. **先整篇通读一遍**，只为建立叙事手感（不做笔记）
2. 量化范文的这些维度
3. 用**同一组维度**量化自己的稿子
4. **差距最大的一项先改**
5. 改完按同一量表自比一次

### 量表维度

每一维都给了「怎么量」，任意范文都能在一次通读内测出——不要绑死在某一篇的数值上。

| 维度 | 量什么 | 怎么量 |
|---|---|---|
| 节数与各节页数 | 每节占全文比例 | 数 `\section`；各节起止页码相减 ÷ 正文总页数 |
| 各节叙事职能 | 一句话概括这节在全文中干什么 | 读每节首段，写一句话 |
| 单段句数 | 平均值与最大值 | 抽 5 段数句号；记最长那段 |
| **限定 / 防御句数量** | 全文计数 | grep「不能/不等同于/并不表示/尚不能/not/cannot/does not imply」 |
| 引文密度 | 每页引用次数 | 全文 `\cite` 数 ÷ 正文页数 |
| 图表出场次序 | 第一张图在第几页、是什么类型 | 翻到第一个浮动体，记页码与类型 |
| 摘要数字粒度 | 是否出现逐条件数值 | 读摘要，数出现的具体数字个数 |

**量级差本身就是病灶信号**。本项目实测：自己稿 60+ 句防御性表述 vs 范文 <5 句——这一项差 12 倍，是当轮第一优先级。

## 五、从范文提炼 5–8 条可检查的叙事规则

通读后把规则写进任务文件，之后按规则写作并逐章对照自检。规则要写成**可逐条检查**的形式：

```
1. 段落间是否单线因果（每段只做一件事）
2. 方法小节是否遵循固定节拍（动机 → 对策 → 公式）
3. 防御性限定句的数量上限与允许出现的位置
4. 图注是描述还是辩解
5. 结果段首句是结论还是指路
6. 实验章是否先给单例证据链再给统计曲线
7. 相关工作是否按方法族组织并给适用性判据
```

## 六、本项目从范文学到的具体几条

对照旧英文稿 → 定稿的实际改动，这几条是范文对标直接带来的：

| 层面 | 旧稿 | 定稿 |
|---|---|---|
| 章节数 | 8 节（旧英文稿） | **6 节**（中文首稿 7 节 → r6 把讨论并入结果） |
| 引言起笔 | 技术设定（"A lower radar reporting threshold…"） | 领域对象定义（「群目标是指⋯」） |
| 相关工作 | 否定式（「不能处理」） | 先肯定成立的贡献，再指出未覆盖的那一层 |
| 摘要 | 以「消融不能说明什么」收尾 | 以「方法达成什么 + 全面优于基线」开头 |
| 实验章 | 只有汇总曲线 | 七图证据链 + 统计曲线 |
| 方法章开头 | 直接进模型 | 总流程图 + 两个算法框 |
| 复杂度小节 | 混在讨论里 | 独立小节，位置对齐范文 |
| 摘要数字 | 逐条件计数 | 零细粒度数字 |

> **不要把「页数变少」当成对标收益。** 本项目旧英文稿 11 页 / 4 图，定稿 20 页 / 16 图——增页来自新增的七图证据链。真正被压缩的是中文重构前稿（26 页 → r6 后 19 页），那是另一条基线，不要与英文稿混为一谈。

## 七、范文对标不能替代的东西

范文给的是**结构与篇幅配比**。以下三项范文不提供，必须自己保证：

1. **claim 与自己证据的匹配**——范文的结论强度对应它自己的实验规模
2. **术语的本文一致性**——范文的术语体系不一定适合本文的方法
3. **数值的可复现性**——范文不会告诉你哪些数字该走宏

对标做完后，仍要走 [04-hedging.md](04-hedging.md) 的额度核账和 [06-evidence.md](06-evidence.md) 的证据闭环。
