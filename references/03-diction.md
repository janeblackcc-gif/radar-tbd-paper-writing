# 03 · 词汇层：黑话治理

> 适用语言：主线通用；标注「【中文】」的条目为中文母稿特有，另见 [10-chinese.md](10-chinese.md)

**结构定稿后单开一轮，只做措辞，不碰结构。** 混在结构轮里顺手改，两层都治不干净。

## 一、判定黑话不靠语感

长期共事者的语感三个月就被内部词汇污染。**行话的定义就是写的人已经读不出它是行话。**

两条外部判据，命中任一即为黑话：

1. 圈外同行一眼看不懂
2. 目标期刊近年录用论文里不出现

对应手段是两张表 + grep 清零，不是逐句人工阅读判断。

## 二、禁用词表与正名表配套使用

**禁用词表**管「不许出现」，**正名表**管「换成什么」。只有前者会导致删了了事，只有后者会漏掉没想到的词。

### 禁用词表（本项目实测 33 词，按类分组）

**流程治理类**——描述的是你的工作方式，读者只需要科学动作和科学量：

```
提交号  commit  冻结  freeze  注册  封存  清单  manifest
作废  执行窗口  数据指纹  哈希  SHA  证据链  工单号  战役
审计  合同  payload  case  trial  留出  揭盲  口径
```

**内部造词类**——本次工作流程中造出来的复合词：

```
成功回放   三臂消融   共享随机种子   核心网格   评价协议
××单元    ××回放    覆盖零        形成自洽表述
可认证前沿搜索   确定性刚体匀速真值协议
```

**判定准则**：这个词在本领域已发表文献里查不到、是本次工作流程中造出来的，就进表。典型形态是「过程/统计口径」类复合词。

### 正名表（黑话 → 期刊语言）

替换方向是**换成读者已经在用的说法，不是换一个自造词**：

| 黑话 | 正名 |
|---|---|
| 6300 次执行 | 每个条件 100 次 Monte Carlo 仿真 |
| 七个预设算法 | 七种对比算法 |
| 评价协议 | 性能评价方法 |
| 主成功判据保持不变 | 跟踪成功的判定标准为⋯ |
| 配对区间覆盖零 | 两者之差的 95% 置信区间包含 0，差异在统计上不可分辨 |
| 可认证分支定界前沿搜索 | 带上界剪枝的分支定界搜索，给出精确值或误差有界的区间估计 |
| 确定性刚体匀速真值协议 | 目标作匀速直线运动，编队保持刚性 |
| 留出种子 / 证据状态 / 清单哈希 | 每种条件 N 次独立 Monte Carlo 实现，无已完成运行被剔除 |
| 一致的转折位置 | 三条曲线的拐点出现在同一 SNR 条件 |

**两条边界**：

1. **区分「内部方言」与「领域标准术语」**。判据是「本刊读者是否认得这个词」。领域内公认的方法学术语不在清除之列。
2. **清除的是外壳不是事实**。把治理术语改写成读者语言并**保留其信息量**，而不是整句删掉。

**自查法**：把句中的治理词替换成它对应的科学事实，替换不出科学事实的句子通常整句可删。

### 标准术语保持标准写法

只替换本项目自创的写法。置信区间、RMSE、Monte Carlo、GOSPA 这类标准术语保持标准简洁写法，**不要反向展开成长句**。

### 内部标识零进正文

内部文件名、配置键、SHA、清单文件名、分支名、待定署名与经费占位、内部审议与评审往返记录、与 AI 工具的协作痕迹，一律不进正文——**包括节标题、图注、表头、页眉和致谢**。需要留档的版本信息移入元数据或补充材料。

定稿前逐句过一遍自检问句：**这句话会不会暴露写作过程本身。**

注意区分：「科学局限」必须写进正文，「流程状态」一律清除。前者是结论的边界，后者是你的工作方式。

## 三、新词落笔前过三关

每引入一个新词，逐关检查：

| 关卡 | 检查 | 判定 |
|---|---|---|
| 同义重复 | 全文是否已有词指同一操作 | 有则复用既有词 |
| **一词双义** | 该词在别处是否已有别的含义 | 有则换词——**比生僻更致命** |
| 直译 | 是不是英文 calque | 是则换领域惯用说法 |

第四关（可选）：是否与领域已有成熟术语**字面撞名**——读者会按既有含义理解。

本项目实例：

- 「种子」已用于 random seed，就不能再指优化初值 → 一词双义
- 「粒子群」会被读成 PSO → 撞领域专名

### 批量检测新造词

取本轮全部新增行的候选词，**对比上一定稿与当前稿的全文计数**——计数从 0 起跳的即为新造词，逐个过关。

### 拒绝一次性外来术语

不要为了显专业引进一个全文只出现一次的外来术语。在稿内数该词出现次数即可判定。

任一关命中就换词，并把该决定连同判据**写进术语表**，避免下一轮又改回来。

## 四、术语表四列

| 冻结词 | 首选外文 | 使用语境 | **避免用法** |
|---|---|---|---|
| 槽位 | slot | 指编队内的几何索引位置 | 不写 true leader；不暗示已知真实物理身份 |

**第四列是关键。** 只给正确词拦不住误用——它要写明该词不能被误解成什么、不得外推到什么。

第四列是可执行的：`python scripts/term_variants.py --config paper.gates.json` 把第四列里的反引号词、英文短语、「不写 / 不用 / 不称 X」后的 X 当作避免形式，在源码散文（含图注）和 PDF 抽取文本里出现即 HARD_FAIL，可在 `paper.exemptions.json` 的 `term_variants` 键下逐条豁免。术语表文件由配置的 `glossary` 键指定，表头须含「冻结词」「避免」两词；「不与 / 不把 / 不暗示 / 不声称」开头的说明句不取。

配套硬规则：算法内部的数学索引名可以在公式里用，但**不能当标题或摘要里概括研究对象的主词**。

术语表是工作草稿而非终审依据：后续若某个已冻结词不过读者判据，以读者判据为准并回改术语表。

## 五、定义桥

内部几何 / 实现类术语首次出现时，用一句话挂到读者已知概念上：

> 「⋯任务输入给出各成员的**体坐标位置偏移（下称槽位）**」

按全文顺序，该词的**第一次出现就必须是这座桥**，之前的章节一律改用通俗说法（用「成员之间固定的相对几何」代替尚未定义的「体坐标槽位」）。

### 全局替换会制造「先用后定义」回归

这比「定义早于首次使用」本身更需要盯：把靠前章节的内部术语批量换成读者语言后，**原本承载定义的那句话常被一并改写或删掉**，术语在全文的首次登场就悄悄迁移到后面某个不带定义的位置——读者正好在那里卡住。

**每做一次全局术语替换或整章重写，都要 grep 该术语在全文的首次出现位置**，确认那一处仍带定义桥；否则在新的首次出现处补回。

同样方式复查：缩写全称、以及「领航目标（leader）」这类中英对照注释——重写摘要和引言时它们最容易随旧句一起消失。

### 双向 grep 核账

| 方向 | 期望 |
|---|---|
| 术语在定义章之前的命中数 | 0 |
| 描述性说法在定义之后的命中数 | 0 |

摘要例外——摘要必须自足，可以先用后定义，但要在摘要内就地给出最短解释。

## 六、同一概念只用一个词形

**查法**：列出该概念的所有候选同义词做全文计数，**计数为 1 的孤例通常就是要改的那个**。

**归一目标不是「多数派词形」，而是定义处和摘要里使用的词形**。若多数派与定义不一致，要改的是多数派。

**声明给机器**：同一概念的非规范形态写进配置 `concept_groups`（`{"转弯率假设": ["率切片", "转弯率切片"]}`），`term_variants.py` 默认记待审，`--enforce` 后为硬门。机器猜不出「切片 ≈ 假设」是同义，也猜不出「率条件初态」（rate-conditioned）**不是**——同义关系必须由人声明；脚本的后缀词族列表（假设/切片/条件/构型/槽位/量测/关联…）只是信息提示，定稿上照样会列出「过门限 / 低门限」这类本就不同的概念。规范词的子串形态（率假设 ⊂ 转弯率假设）自动扣除，不必重复声明。

## 七、改名必须扫六个位置

一次改名不能只 grep 正文段落：

1. 正文
2. 表头
3. 图注
4. **图内文字**（含生成该图的脚本源——改完要重跑）
5. 伪代码 / 算法框
6. 补充材料

正文与补充材料之间的不一致最容易残留到定稿，因为两份文件通常不在同一次编辑里打开。

收尾以**旧名的出现计数归零**做闭环验证——范围限于上述六个位置里**本轮进入编译的**部分：`.tex` 正文与补充材料、图生成脚本、参考文献；**不含**历史稿、归档交付单、交接文件与任何批注原件（改写批注原件违反 [09-mechanics.md](09-mechanics.md) 第九节的只读红线，并毁掉审计留痕）。新旧两个名字各 grep 一次：

```bash
python scripts/jargon_scan.py --patterns <旧名> --tex sections_zh --tex si --pdf dist/<当前>.pdf
```

## 八、清零验收必须双范围

扫描对象是两个：

1. `.tex` 源码
2. **最终 PDF 经 `pdftotext` 抽取的可见文本**

> Windows 下 `pdftotext` 不带 `-enc UTF-8` 会把中文**全部静默丢掉**，只剩拉丁字符与数字——2026-09-02 在两篇稿上实测默认编码抽出 0 个汉字，曾被误判为「PDF 无 ToUnicode 映射」。本 skill 的脚本已内置该参数；手工核验时同样必须带。

坐标轴标签、图例和图内标题同样是读者可见文本，且**通常由绘图代码直接继承变量名，是行话残留的最高发区**——它们在 `.tex` 里 grep 不到。

保留扫描表达式、范围和退出码作为交付证明。

### 抽取工具的两个盲区

1. **位图图片和已转曲的文字不会被抽出**——这类图必须逐页目检，否则会拿到一个假的零残留结论。
2. **换行会切断短语造成假阴性**。命中 0 时先换更短的片段复查（本项目实例："linked into arcs" 命中 0 实为换行伪影，换 "into arcs" 后命中）。

### 实证：双范围为什么不能省

在本项目**已定稿的 r22** 上用 `scripts/banned-terms-template.txt` 跑一遍：

| 范围 | 结果 |
|---|---|
| `sections_zh/*.tex`（排除 `algorithmic` 环境） | 命中 0，退出码 0 ✓ |
| `dist/r22_full.pdf` 抽取文本 | **原始命中 5，退出码 1**：4 处落在算法 1 的英文伪代码体内（按本节下一小节的规则人工豁免），剩 1 处 `runtime` 是真残留 |

那 1 处是**图 16**（LaTeX 标签名是 `fig:zh-results-14`——标签名不等于渲染图号，这本身就是同类陷阱）的 y 轴标签 `"Median runtime per run (s)"`，写死在 `figures/gen_fig_b5_results.py` 的 `y_label` 里——**在 `.tex` 中 grep 不到**，而它在版面上和正文一样醒目（同图另一个轴标签是 `"Peak memory (GiB)"`，中文图注却是「每次仿真的中位运行时间与峰值内存」）。

只扫源码就会得出「全稿零残留」的结论。

> **验收口径不是「退出码必须为 0」**，而是「**PDF 侧命中数 = 已人工判定豁免数，且每条豁免在交付说明里逐条列出理由**」。有算法框的中文稿退出码必然为 1（见下一小节），拿退出码 0 当唯一门槛会逼你删掉本文的核心概念名。


### 伪代码环境要显式排除

中文母稿的算法体按期刊惯例写英文（见 [10-chinese.md](10-chinese.md)），其中的英文**不是**行话残留。不排除它，有算法框的稿子永远无法清零：

```bash
python scripts/jargon_scan.py --patterns banned.txt \
    --tex sections_zh --exclude-env algorithmic --pdf dist/r22_full.pdf
```

PDF 侧无法排除环境——落在伪代码块里的命中需人工判定豁免。

配套脚本：`scripts/jargon_scan.py`。

## 九、抽象壳词换成学科词

把流水线壳词换成该学科里具体的实验语义词：

```
输入 / 输出 / 形态 / 表述 / 机制展示 / 产物
```

（「口径」已在第二节的流程治理类禁用词表里，走 grep 清零，不重复列。）

**判断法**：同第一节的判据一——念给同领域外行听，如果他要追问「这具体指什么」就得改。

## 十、拆掉自造的多层定语复合名词

**检测判据**（两条同时满足即为自造词，必须改写）：

- 三层以上修饰语连缀
- 在任何被引文献中都查不到

一律拆成主谓句或动词短语：

| 自造复合名词 | 拆解后 |
|---|---|
| 可认证分支定界前沿搜索 | 带上界剪枝的分支定界搜索，给出精确值或误差有界的区间估计 |
| 配对区间覆盖零 | 两者之差的 95% 置信区间包含零，差异在统计上不可分辨 |
| 确定性刚体匀速真值协议 | 目标作匀速直线运动，编队保持刚性 |

【中文】相关的名词链与翻译腔问题见 [10-chinese.md](10-chinese.md)。

## 十一、自造缩写不得当术语用

不要把「数量+类别」的自造缩写反复使用：

```
三个变体   两条路线   三臂消融
```

凡被当作**结论承载单位**引用的数量代号，在首次出现处就地逐项展开。如果摘要中的某条结论依赖它，**摘要内就要展开**，不能要求读者去正文找对应关系。

## 十二、统计结论不用自造简称

报告统计结论时展开成完整判断句，三个槽位缺一不可：**是什么量、和什么比较、得出什么结论**。

```
✗ 「区间覆盖零」
✓ 「两个 95% 置信区间均包含零，差异在统计上不可分辨」
```

只给统计事实不给判读结论的句子一律视为未完成。

## 十三、按读者可见度分级控制措辞

| 层级 | 措辞 |
|---|---|
| 标题、摘要、引言 | 最克制，只用读者语言 |
| 结果与讨论 | 可展开 |
| 数学定义处 | 可用内部精确术语 |

同一概念**允许**在不同可见度层用不同说法，但必须在定义处建立对应关系（即定义桥）。

这条修正了「全文术语必须完全一致」这条朴素规则，正好解决在「精确内部术语」与「读者可读」之间反复摇摆的困境。

## 十四、去 AI 味

第一优先级**不是**删破折号或换同义词，而是清除项目内部的流程 / 治理方言（见第二节）——这类词让读者一眼看出文本是从内部工作流复制来的，比任何句式问题都致命。

第二抓手是一次机械的**词密度扫描**，而不是套话清单：

1. 挑出全文出现异常频繁的功能词与限定词（如「预设」「值得注意的是」「此外」）
2. 逐处判断是否承担实际语义
3. 只保留必需的那几处，其余换同义词或删除
4. 括号、破折号、连接词按同样方式**按密度复核**，不是按清单一刀切

> **反向护栏**：不要给每段机械加「然而/因此」连接词。连接词密度过高本身就是 AI 腔的显著特征。按因果关系真实需要加。

机器版的密度扫描是 `scripts/style_audit.py`（第 4 层，软诊断，只出热区）：模板句 / 千字、连接词起句比、名词链、句长节奏、结果段首都在里面，两篇真稿的基准值记在 [13-style-audit.md](13-style-audit.md) §五。第 4 层的职责、「无明确问题不改」和优先级见 [11-naturalness.md](11-naturalness.md)：

```
事实与逻辑完整  >  术语与格式稳定  >  语句清楚  >  风格变化
```

任何去 AI 味的改写若要动数字、方向、冻结词或唯一边界句，不改。

### 硬边界

本条只处理措辞冗余，**不改**数值、单位、符号、图表编号和技术含义。学术上必要的限定词一律保留，不为去 AI 味而口语化。

「这个限定该不该做」是另一个问题，见 [04-hedging.md](04-hedging.md)。

## 十五、有名无值的限定语

「按预设容差 / 在预设资源内 / 预设上限」这类只给名义不给数值的限定，二选一：

1. **就地补上具体数值**并逐个对准实现核验
2. **整句删除**

它占的篇幅和直接写出数值几乎一样，却让读者既无法判断合理性也无法复现。

内联写法：

> 「若两者间距差满足预设容差（75 m 与槽位间距 15% 中的较大者）」

内联的每个数值必须**逐个回到代码或冻结配置核对**，不得凭记忆或上下文推断填写。

配置参数正文内联、聚合结果走生成宏——这条约定见 [06-evidence.md](06-evidence.md)。

## 十六、定义句用直陈式

```
✓ 「X 的判定标准为：⋯」
✗ 「从实验前到聚合后保持不变的判据为：⋯」
```

不要把流程纪律当定语挂在定义上。

**但要区分**：预注册、参数在见结果前冻结这类声明**本身有辩护价值**，处理方式是移到方法或复现小节集中陈述一次，而不是删除。真正该删的是不承载信息、只体现内部纪律的修饰。

## 十七、限定语准入测试

该形容词暗示的对照在稿中**真实存在**才保留。

「完整方法」只出现在与消融变体对比的段落，其余场合直接写方法名。

删除前先判断它是否**承载方法学决定**（如「保守判失败」实际定义了歧义时如何计数）：

- 承载的 → 移到方法小节一次性说明
- 不承载的 → 直接删

不要在正文每次提及时都挂一遍。

## 十八、评审质疑某个词时的处理

先判定它是否为该领域**标准译名或既有专名**，依据限于：

- 目标期刊近三年论文
- 领域教科书
- 该概念的原始文献

是 → 保留原词，在首次出现处加英文括注。
核查不出既有用法 → 按意见改。

**无论改与不改，都要在交付汇报里写明结论和依据**——保留可以，静默保留不行。
