# 卡片 · 引言

**触发**：`hedge_position`（引言出现防御句，hedge_budget）；`template_phrase` / `connector_density` 落在引言（style_audit）；人工判定「缺口句不唯一」「方法名出现过早」「第一句立技术设定」。依据：02-narrative §引言。

## 允许改
- 第一句改成先立研究对象（定义 + 两三个实例），删「近年来 …… 受到广泛关注」类起句。
- 把方法名的首次出现后移到缺口句之后。
- 缺口句合并为全文唯一一句，并与贡献第一条一一对应（措辞对得上）。
- 删三类段落：泛化背景、与因果链无关的技术科普、对相关工作的重复评价。
- 引言里的防御句删除，或改写成中性的适用性判据（「其适用性取决于观测模型与计算预算」）。

## 禁止改
- 贡献列表的条目数与顺序（结构层决定；要改先改大纲文件）。
- 引用键与其绑定的论断（02-narrative §论断—引用绑定）。
- 摘要与结论——引言改了 claim 强度，同步只能走 `hedging-balance`。
- 相关工作章的内容（另一张卡片）。

## 必保留
- 顺序：对象 → 为什么难 → 现有路线 → 逐个点名的具体缺陷 → 一句缺口句 → 本文方法 → 贡献 → 组织。
- 缺口句全文只出现一次。
- 段落 3–5 句、引言 5–7 段（10-chinese §九）。

## 自检与停止
- `hedge_budget` 位置项转绿；`style_audit` 引言段无高优先级热区。
- 复述全文最短因果链：引言每段都能挂到链上的某一步；挂不上的段删除，不改写。
- 同一段最多 2 次。
