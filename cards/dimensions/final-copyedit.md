# 卡片 · 终稿措辞（术语与指代）

**触发**：`jargon_hit`（jargon_scan）；`term_variant`、`avoided_form`（term_variants，M2）；`unclear_reference` / `synonym_drift`（style_audit，M3）。

## 允许改
- 按正名表把黑话换成期刊词；按术语表第四列把「避免用法」换回冻结词。
- 同一概念的多形态（如 率切片 / 率假设 / 率条件 / 转弯率假设）统一到术语表冻结词，**含图注与图内标签**（改绘图脚本的数据/标签层，不动样式层）。
- 把无唯一指向的「其 / 该方法 / 这一点」换成原文已有的准确名称。
- 删同一信息的近义复述（原文确有两层含义时两层都留）。

## 禁止改
- 术语定义句本身（定义桥）。
- `algorithmic` 环境内的英文（伪代码体按期刊惯例写英文）。
- 公式符号、参数符号。
- 为了「不重复」把核心概念换成同义词——同一概念只用一个词形（03-diction §六）。

## 必保留
- 先定义后使用的顺序（全局替换会制造「先用后定义」回归，03-diction §五）。
- 改名扫六个位置：正文、图注、图内标签、表头、算法框、术语表。

## 自检与停止
- `jargon_scan` 命中数 = 豁免数，豁免逐条列理由；`term_variants` 无 HARD_FAIL。
- 双范围：源码 + `pdftotext -enc UTF-8` 抽取文本。
- 一次统一完即停；不在同一轮顺手改句法。
