# 卡片 · 结论先行修复（结果章）

**触发**：`figure_first_opening`（段首是「图 X 给出 / 如图所示」）、`claim_far_from_evidence`（断言句附近没有图表 / 数字 / 区间钩子）、文档级 `result_first_ratio` 偏低——style_audit。依据：02-narrative 结果章 §段首、§每图 2–3 句解读。

## 先判断
- 该段是证据链的「展示段」（场景表 → 真值 → 含噪观测 → ……）还是「结论段」？展示段的段首本来就是「图 X 为同种子实例的 ……」，允许保留，记豁免 `pointwise_declaration` 以外的说明性理由。
- 结论段：段内有没有现成的现象句？有 → 只做移位；没有 → 这是内容缺失，登记 PLAN_DISCREPANCY（09-mechanics §五），不在本卡片里新造结论。

## 允许改
- 把段内已有的现象 / 比较句移到段首，「图 X」改为句末括注或第二句。
- 「现象 + 机制」顺序：现象句紧跟其机制句；机制句若离得远，移近。
- 断言句附近补上**已有的**钩子：同段的图表编号、已有的宏、已有的区间陈述。

## 禁止改
- 新造结论、新造数字、改比较方向、改区间是否包含零。
- 图注文字、图内容、浮动体位置（那是 `page_blank` 的卡片）。
- 「该实例按什么机械规则选出」那句。
- 消融边界句（例：「消融结果尚不能区分各部件的独立贡献」类句子若在闭环表里有豁免标签，不动）。

## 必保留
- 同种子证据链的顺序；每图之后 2–3 句解读仍在。
- 段首句与闭环表里对应主张的措辞一致（claim 强度不得因移位变强或变弱）。

## 自检与停止
- `style_audit` 该段 `figure_first_opening` / `claim_far_from_evidence` 消失；`result_first_ratio` 不降。
- `semantic_diff` 该段 PASS（只移位不改事实时必然 PASS；否则说明改多了，回滚）。
- 同一段最多 2 次；展示段不进第二次。
