# ══ C. 中文内部造词（示例——新项目必须整节替换）═══════════════════

# ══ 人工复核候选（不激活，通读时按语境判断）═══════════════════════
# 这些词在中文里有合法用法，不能机械清零；但一旦以「流程治理」义出现，
# 就要按 references/03-diction.md 的正名表替换。
#
#   口径  清单  注册  冻结  封存  合同  留出  审计  作废  揭盲
#   提交号  哈希  战役  工单号  单元  产物
#
# 自查法：把句中的词替换成它对应的科学事实（「执行 N 次」→「进行 N 次
# Monte Carlo 仿真」）。替换不出科学事实的句子通常整句可删。
#
